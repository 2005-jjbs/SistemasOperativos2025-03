# SistemasOperativos2025-03  
Este repositorio recopila los programas desarrollados durante la asignatura **Sistemas Operativos (2025-03)**. Todos los ejercicios y prácticas están implementados en lenguaje C, abordando conceptos fundamentales como gestión de procesos, concurrencia, memoria, sistemas de ficheros, entre otros.

---

## 📂 Estructura del repositorio  
A grandes rasgos, el contenido se organiza en carpetas según cada unidad o práctica.  
Algunas de las carpetas más relevantes son:

- `Taller01_Ballesteros`  
- `Taller02fork`  
- `Taller_03_SincroPosix`  
- `Taller_Fork_Ballesteros`  
- `forkpipe_Ballesteros`  
- `laboratorioOpenMP`  
- `MultiplicacionMatrices_Ballesteros`  
- `Laboratorio_Sistema_Ficheros`  
- `ProyectoFinal_SO`  

Cada carpeta contiene los archivos fuente (.c, .h) y, en su mayoría, un Makefile para compilar el ejercicio.

---

## 🧠 Contenidos y objetivos  
Los ejercicios incluidas permiten practicar y consolidar temas clave de Sistemas Operativos, por ejemplo:

- Creación, finalización y sincronización de procesos (fork, wait, exec)  
- Comunicación entre procesos (pipes, redirecciones)  
- Concurrencia y sincronización (semáforos POSIX, mutexes)  
- Gestión de memoria, asignación dinámica, uso de hilos (threads)  
- Uso de tecnologías paralelas como OpenMP  
- Implementación de un sistema de ficheros básico (Laboratorio_Sistema_Ficheros)  
- Proyecto final que integra varios de estos conceptos en un sistema más amplio (`ProyectoFinal_SO`)
